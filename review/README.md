# Вичитка

## Зручна сторінка

Запусти в корені проєкту:

```bash
python3 review/live_review.py
```

Відкрий `http://127.0.0.1:8765`. Якщо порт уже зайнятий, запусти `python3 review/live_review.py 8766` і відкрий адресу з цим номером.

- У лівому списку — усі рецепти, зліва від тексту — фото, праворуч — повний текст рецепта.
- Нерозпізнані фрагменти мають вигляд `[підказка]` і підсвічені.
- Виправ текст у квадратних дужках або перепиши весь виділений рядок. Після виходу з поля (або `Ctrl+Enter`) зміна відразу записується до рецепта, оновлює каталог та прибирає закрите питання зі списку.
- `ОК`, «Не прочитати» й «Видалити» також застосовуються одразу.

## Порядок
1. **`заміни.md`** — спочатку. Рецепти, де перше читання описало не той текст, що на фото.
   Постав `[x]` біля потрібних і запусти `python3 review/replacements.py apply --write`.
   Поки рішення немає, питання цих рецептів сховані з `перевірити`.
2. **`перевірити.html` / `перевірити.md`** — решта питань (нижче).

Фото: браузер (крім Safari) не показує HEIC. В архіві `photos/` — JPG-копії (1400 px) з правильною орієнтацією.
Для нових HEIC: `python3 review/heic2jpg.py IMG_xxxx.HEIC photos/IMG_xxxx.jpg`.

1. Поклади всі фото в `photos/` у корені проєкту (або обери папку кнопкою в HTML).
2. Відкрий `перевірити.html` у браузері. Зліва фото, справа питання.
   - `Enter` — зберегти й перейти до наступного відкритого
   - `Alt+1` ОК · `Alt+2` не прочитати · `Alt+3` видалити рядок
   - `стара => нова` — заміна фрагмента; будь-який інший текст замінює рядок повністю
   - відповіді автоматично зберігаються в браузері; наприкінці натисни «Зберегти відповіді.json»
   Альтернатива: заповнюй `Відповідь:` прямо в `перевірити.md` (формат той самий).
3. Перевір, що зміниться (без запису):
   `python3 review/apply_review.py --json відповіді.json`
4. Запиши зміни:
   `python3 review/apply_review.py --json відповіді.json --write`
   Прибираються вирішені маркери, піднімається confidence, оновлюються catalog.csv/manifest.yaml/index.md,
   ведеться журнал у `review/перевірено.md`, а `перевірити.md/.html` перегенеровуються з рештою питань.

Відповіді можна вносити частинами: номери Q стабільні між запусками.
Ручні правки рецептів → `python3 review/build_review.py`, щоб оновити список.
