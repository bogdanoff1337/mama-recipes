## 💡 Що це і навіщо

У кожній родині є той самий потертий зошит: сторінки в плямах від варення, пропорції «на око», половина записів — олівцем, і ніхто, крім мами, вже не розбере, що там написано.

Цей репозиторій — спроба зберегти такий зошит:

- **Не загубиться.** Фото кожної сторінки + текст лежать у Git, а не в одному примірнику на кухонній полиці.
- **Легко знайти.** Рецепти розкладені по розділах і тематичних групах, а не в хаотичному порядку сторінок блокнота.
- **Можна читати будь-де.** Кожен рецепт — окремий `.md`-файл, який гарно відкривається прямо на GitHub, з телефона, в Obsidian чи будь-якому редакторі.
- **Чесно щодо точності.** Розпізнаний рукопис не ідеальний — тому сумнівні місця не вигадані, а позначені й винесені на перевірку «з мамою».
- **Шаблон для інших.** Хочете так само оцифрувати бабусин зошит? Структура та скрипти вичитки тут же — беріть і користуйтесь.

## 🚀 Як користуватись

### Просто готувати

1. Відкрийте **[index.md](index.md)** — це зміст книги.
2. Знайдіть рецепт і клацніть на нього (або йдіть у папку [`recipes/`](recipes/) за розділом).
3. Сумніваєтесь у цифрі? У кожному рецепті вказано, з якого фото його взято (`source_images`) — відкрийте фото в [`photos/`](photos/) і звірте з оригіналом.

> 💡 Шукати зручно через пошук файлів GitHub (клавіша `T` на сторінці репозиторію), або завантажте [catalog.csv](catalog.csv) в Excel / Google Sheets і фільтруйте за розділом чи групою.

### Завантажити собі

```bash
git clone https://github.com/bogdanoff1337/mama-recipes.git
```

Або кнопка **Code → Download ZIP** на GitHub. Папку можна відкрити як vault в [Obsidian](https://obsidian.md) — вийде готова кулінарна книга з пошуком.

### Що означає `confidence`

Кожен рецепт має оцінку, наскільки впевнено розпізнано рукопис:

| Значення | Що означає |
|---|---|
| `high` | прочитано впевнено, можна готувати |
| `medium` | загалом зрозуміло, але варто глянути на фото |
| `low` | багато нечитабельного, обов'язково звірте з оригіналом |

Місця, які не вдалося прочитати, всередині рецепта позначені як `[підказка]` або коментарем `<!-- ?? -->`.

## 🗂️ Структура репозиторію

```text
.
├── index.md              # зміст книги: розділ → група → рецепт
├── catalog.csv           # таблиця всіх рецептів (для Excel / Sheets)
├── manifest.yaml         # машинозчитуваний каталог (для скриптів)
├── recipes/              # усі рецепти, по одному .md на рецепт
│   └── 01-konservatsiya/
│       └── ohirky/
│           └── 002-ohirky-v-tomati.md
├── photos/               # фото сторінок оригінального блокнота (JPG)
├── схожі-рецепти.md      # близькі варіанти, які навмисно НЕ злиті
├── дублікати.md          # рішення щодо дублікатів
├── перевірити.md / .html # відкриті питання для вичитки
├── заміни.md             # пропозиції з повторного читання фото
└── review/               # скрипти вичитки та службові дані
```

### Формат рецепта

Кожен файл — Markdown із YAML-шапкою:

```markdown
---
id: "148"
title: "Варення з полуниці"
source_images:
  - "IMG_1662.jpg"
category: "Десерти"
group: "Варення"
tags: ["полуниця", "варення"]
confidence: "high"
---

## Інгредієнти
- полуниця — 3 л
- цукор — 1,5 л
- вода — 0,5 л

## Приготування
Кип'ятити 5 хв.
```

Мірки збережені так, як у мами: «склянка», «л», «ст. ложка», «на око» — без перерахунку в грами.

### Принцип упорядкування

- Порядок сторінок блокнота **не** диктує порядок книги: `розділ → тематична група → схожі рецепти поруч`.
- Рецепти зі схожими назвами, але різними пропорціями **не зливаються** — вони лежать поруч як варіанти (див. [схожі-рецепти.md](схожі-рецепти.md)).

## ✍️ Вичитка й виправлення

Розпізнаний рукопис потребує людської перевірки. Для цього є інструменти в [`review/`](review/) — потрібен лише **Python 3** (стандартна бібліотека; для HEIC-фото ще `Pillow`).

**Найзручніше — живий редактор у браузері:**

```bash
python3 review/live_review.py
```

Відкрийте `http://127.0.0.1:8765`: зліва список рецептів, поруч фото сторінки й повний текст. Нечитабельні фрагменти підсвічені — виправляєте прямо в полі, і зміна одразу записується в рецепт, а каталоги оновлюються автоматично.

**Або класичний цикл через файл відповідей:**

```bash
python3 review/build_review.py
python3 review/apply_review.py --json відповіді.json
python3 review/apply_review.py --json відповіді.json --write
```

1. Перший — збирає всі сумнівні місця в `перевірити.md` / `перевірити.html`.
2. Другий — показує, що зміниться (нічого не записує).
3. Третій — застосовує відповіді, піднімає `confidence`, оновлює `index.md` / `catalog.csv` / `manifest.yaml` і веде журнал у `review/перевірено.md`.

Детальна інструкція з усіма форматами відповідей — у **[review/README.md](review/README.md)**.

Нове фото з iPhone у HEIC? Конвертуйте в JPG:

```bash
python3 review/heic2jpg.py IMG_xxxx.HEIC photos/IMG_xxxx.jpg
```

## 🤝 Як долучитись

Знайшли помилку, впізнали нечитабельне слово або перевірили рецепт на практиці?

- **Не програміст?** Створіть [Issue](https://github.com/bogdanoff1337/mama-recipes/issues): номер рецепта + що не так.
- **Знаєте Git?** Відредагуйте `.md`-файл рецепта (можна просто олівцем ✏️ на GitHub) і відкрийте Pull Request.

Будь ласка, не «покращуйте» рецепти на свій смак — мета зберегти саме те, що записала мама. Свої варіанти краще додавати окремим рецептом із позначкою.

1. Сфотографуйте кожну сторінку блокнота при денному світлі.
2. Зробіть fork цього репозиторію (або скопіюйте структуру).
3. Замініть вміст `photos/` і `recipes/` своїм — розпізнати текст із фото допоможе будь-який сучасний AI-асистент.
4. Сумнівні місця позначайте `<!-- ?? -->` і проходьте вичитку скриптами з `review/`.
5. Сядьте з мамою чи бабусею над `перевірити.html` — це, чесно, найкраща частина всього процесу. ❤️
